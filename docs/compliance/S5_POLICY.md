# S5 注销策略：保留内容，清理身份及业务关联

用户决定 C-17／D-01：保留内容，清理账号身份及关联。策略版本 `s5-retain-published-v1`，适用于此后发起的主动注销；本文件是实施契约，不是验收完成证明。

- 账号：撤销全部凭证及扫码票据，持久停用；清微信标识、密码摘要、手机、邮箱、原昵称、头像 URL 和收藏。
- 评价与普通反馈：保留正文、评分、公开回复及既有公开状态；清业务账号关联、联系方式和直接身份副本，移除本人点赞并重算。待审、隐藏和拒绝状态不自动公开。正文中主动写入的个人信息不承诺自动识别或完全匿名。
- 私密投诉：继续私密，保留处理内容与回复，清业务账号关联和联系方式；注销后无法继续通过原账号查看回复。受限历史审计不随业务关联一起清除。
- 支付：保留订单号、交易号、金额、支付状态等对账事实，清账号关联、昵称和备注；新的公开捐助记录使用精确订单键清理昵称。旧公开记录没有精确归属键时，不按同名猜删，明确留人工核对事项。
- 头像：处理本人历史和在途上传，远端删除失败要持久留待重试；源站删除与历史 CDN／第三方缓存清除分别报告，不承诺缓存立即消失。
- 日志：受限安全、管理员和调取记录按既有保留配置处理，不因注销删改历史证据；账号内部编号仍可能存在于受限证据。因此是业务解除关联，并非所有证据不可追溯。
- 重试记录：独立注销账本和受限清理作业保留最小内部编号、账号创建时间、规则版本及必要处理键，以便失败恢复；不保存原昵称、手机号或登录凭证。这些记录也不属于彻底匿名数据。
- 备份：不逐份改写历史加密包；独立保存最小注销账本，隔离恢复后核对最新账本并重放注销，不能用旧包覆盖账本或直接启用旧会话。既有保留配置保持，不新增法定期限判断。

实现需要持久作业、失败／重启重试、同队列内容清理及在途上传收尾；全部必要本地清理完成前不得返回完整成功。真实远端缓存、生产配置和无归属历史捐助记录保持明确边界。
